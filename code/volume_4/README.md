# Volume 4 Lisp source

Transcribed from `PDFs/Knowledge-Based_Editor_Jan-1985_volume_4.pdf`.
Each Lisp file corresponds to a source listing in that PDF. Page numbers below
are PDF page numbers, counted from 1; the printed page numbers restart for each listing.

Indentation has been normalized and running page headers have been omitted.
The historical Lisp Machine dialect, reader syntax, and original copyright notices
are retained. These are source transcriptions, not a port to a modern Lisp.

All 32 files passed a delimiter and string check that accounts for slash escapes
and Lisp Machine character literals. Ambiguous OCR and incomplete existing
transcriptions were checked against the scanned pages. The code has not been
compiled or run in a Lisp Machine environment.
