# Volume 1: Lisp listings

All 30 source listings from [the volume 1 PDF](../PDFs/Knowledge-Based_Editor_Jan-1985_volume_1.pdf) are transcribed below. Existing transcriptions were reused where available, and missing listings and continuations were extracted from the scans. The original `lisp/` directory was left unchanged.

Indentation is normalized. These listings retain the historical Lisp Machine syntax and custom reader forms. Parentheses, brackets, strings, and quote/backquote usage were checked; the code has not been executed.
